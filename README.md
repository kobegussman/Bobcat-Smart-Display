# Bobcat Smart Display

A Texas State–themed desktop smart display built with Python and CustomTkinter. The application displays the current time, date, and live weather conditions for San Marcos, Texas through a modern dashboard interface.

![Bobcat Smart Display](screenshots/home.png)

---

## Features

- 🕒 Live digital clock with automatic updates
- 📅 Current date display
- 🌤️ Real-time weather for San Marcos, TX
- 🌡️ Temperature and weather conditions
- 🏫 Texas State Bobcat themed interface
- 🖼️ Custom Bobcat branding and graphics
- 💻 Desktop application built with Python

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Bobcat-Smart-Display.git
```

Navigate to the project directory:

```bash
cd Bobcat-Smart-Display
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
